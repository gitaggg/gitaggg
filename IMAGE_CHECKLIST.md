## 📐 Recommended Image Specifications

```
Resolution:    1200-2000 px width (high quality)
Format:        JPG or PNG
File Size:     100-500 KB per image (optimize for web)
Aspect Ratio:  16:9 or 4:3 (prevents distortion)
Quality:       Clear, well-lit, no phone blur
```

**Quick Optimization:**
- Use TinyPNG.com to compress before uploading
- Resize with Preview (Mac) or Paint (Windows)
- Keep sharpness but reduce file size to 250KB max

## 🆘 Troubleshooting

**Q: Images not showing up?**
- Check file names (cases matter: `common1.jpg` NOT `Common1.jpg`)
- Check location (must be in `assets/` folder)
- Test in browser (F5 refresh hard cache)

**Q: Images look blurry?**
- Camera was too far or phone moved
- Resize properly (1200px+ width)
- Use better camera if possible

**Q: Images load slowly?**
- File size too large (use TinyPNG)
- Hosting bandwidth (upgrade if needed)
- Old browser cache (Ctrl+Shift+Delete)

**Q: Don't have enough photos?**
- Use stock photos temporarily
- Plan photo shoot soon
- Replace once you have real photos
